# e-plantShopping

Project Overview

e-plantShopping is a dynamic React-based e-commerce web application that allows users to browse a curated collection of houseplants, add them to a shopping cart, and manage their selections before checkout.

Features
Landing Page – Welcoming hero section with company name and a "Get Started" button
About Us Page – Company background, mission, and values
Product Listing Page – Browse 18+ unique houseplants grouped into 3 categories
Shopping Cart – Full cart management with quantity controls, item removal, and cost totals
Redux State Management – Centralized cart state using Redux Toolkit
Responsive Design – Optimized for desktop and mobile viewing

# Tech Stack
React 18
Redux Toolkit
React Router DOM
CSS3
